# COVID-19 Misinformation and the 2020 Presidential Election

## Project Overview

My project investigates the relationship between COVID-19 misinformation beliefs and voting behavior in the 2020 U.S. presidential election. I am using data from the Pew Research Center’s American Trends Panel to link respondents’ beliefs about the origins of the pandemic in March of 2020 to their reported presidential vote choice following the November election.

My primary research question is whether respondents who believed that COVID-19 was intentionally developed in a lab (believing misinformation) were more likely to vote for Donald Trump than respondents who believed the virus came about naturally. I also explore the role of political party affiliation and other potential confounding factors included in my data.

## Data

This project uses three waves of the Pew Research Center's American Trends Panel (focusing on the first two):

- **Wave 63.5 (March 2020):** Contains information about respondents' COVID-19 beliefs, misinformation exposure, political affiliation, ideology, and demographic characteristics.
- **Wave 78 (November 2020):** Contains respondents' reported vote choice in the 2020 presidential election.
- **Wave 79 (November 2020):** Contains respondents’ reported exposure to misinformation about the 2020 election.

Respondents across the waves are linked using the unique respondent identifier `QKEY`.
The `data/` directory also includes cleaned and merged datasets generated by the notebooks.
Link to data folder: https://github.com/ameliabrooks28/QSS20_Project/tree/main/data

## Code

The `code/` directory contains three Jupyter notebooks that run in order:

1. **`00_load_clean.ipynb`** - Loads the Pew datasets and keeps relevant variables.
2. **`01_merge.ipynb`** - Merges respondents across the March and November surveys and creates the main misinformation-belief and vote-choice variables based on existing variables.
3. **`02_analyze.ipynb`** - Conducts exploratory analysis and creates starter visualizations of the relationship between COVID-19 misinformation beliefs, political affiliation, and presidential vote choice.

## Output

The `output/` directory contains figures generated by the 02_analysis notebook.
