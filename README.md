# COVID-19 Misinformation and the 2020 Presidential Election

## Project Overview

My project investigates the relationship between COVID-19 misinformation beliefs and voting behavior in the 2020 U.S. presidential election. I use data from the Pew Research Center’s American Trends Panel to link respondents’ beliefs about the origins of the virus in March of 2020 to their reported presidential vote choice following the November election.

My primary research question is whether respondents who believed that COVID-19 was intentionally developed in a lab (misinformation belief indicator) were more likely to vote for Donald Trump than respondents who believed the virus came about naturally. I also explore the role of political party affiliation, age, education, and prior 2016 election vote to see if an association persists after accounting for confounders.

## Data

This project uses four waves of the Pew Research Center's American Trends Panel (ultimately focusing on the first three):

- **Wave 23 (November-December 2016):** Contains respondents' reported presidential vote in the 2016 presidential election.
- **Wave 63.5 (March 2020):** Contains information about respondents' COVID-19 beliefs, misinformation exposure, political affiliation, ideology, and demographic characteristics.
- **Wave 78 (November 2020):** Contains respondents' reported vote choice in the 2020 presidential election.
- **Wave 79 (November 2020):** Contains respondents’ reported exposure to misinformation about the 2020 election.

Respondents across the waves are linked using the unique respondent identifier `QKEY`.
The `data/` directory also includes cleaned and merged datasets generated by the notebooks.

## Code

The `code/` directory contains four Jupyter notebooks that run in order:
[View the code folder](https://github.com/ameliabrooks28/QSS20_Project/tree/main/code)

### 1. **`00_load_clean.ipynb`**
   [View notebook](https://github.com/ameliabrooks28/QSS20_Project/blob/main/code/00_load%26clean.ipynb)
   **Inputs:** Pew American Trends Panel data sets.
   **Purpose:** Loads each data set, selects relevant variables to keep, and removes na values.
   **Outputs:** Cleaned data sets saved to `data/` directory.
### 2. **`01_merge.ipynb`**
   [View notebook](https://github.com/ameliabrooks28/QSS20_Project/blob/main/code/01_merge.ipynb)
   **Inputs:** Cleaned data sets created by `00_load_clean.ipynb`.
   **Purpose:** Merges respondents across survey waves using `QKEY` linking variable, creates binary variables for COVID misinformation belief and 2016 & 2020 Trump votes, and prints merge diagnostics.
   **Outputs:** Merged data set saved to `data/` directory.
### 3. **`02_analyze.ipynb`**
   [View notebook](https://github.com/ameliabrooks28/QSS20_Project/blob/main/code/02_analyze.ipynb)
   **Inputs:** Merged data set created by `01_merge.ipynb`.
   **Purpose:** Conducts analysis of the relationship between COVID misinformation belief, political affiliation, and 2020 presidential vote choice, and creates starter bar charts.
   **Outputs:** Figures saved to `output/` directory.
### 4. **`03_regression.ipynb`**
   [View notebook](https://github.com/ameliabrooks28/QSS20_Project/blob/main/code/03_regression.ipynb)
   **Inputs:** Merged analysis data set created by `01_merge.ipynb`.
   **Purpose:** Fits logistic regression models predicting 2020 Trump voting from COVID misinformation belief. Models sequentially adjust for existing political party affiliation, age, education, and prior 2016 presidential vote. Converts logistic regression coefficients to odds ratios and creates forest plots with 95% confidence intervals.
   **Outputs:** Regression results and forest plots saved to `output/` directory.
